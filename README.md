# Casa Bigotes

Escaparate editorial estático para recomendaciones de gatos de interior. No vende ni almacena productos propios.

## Publicación gratuita

1. Crear un repositorio público en GitHub.
2. Subir el contenido de esta carpeta a la rama `main`.
3. Activar **Settings → Pages → Deploy from a branch → main / root**.
4. Sustituir la URL de `robots.txt` por la URL real de GitHub Pages.
5. Comprobar que `index.html` y `transparencia.html` se abren sin contraseña.

## Afiliación

No hay enlaces monetizados todavía. Cuando Amazon apruebe la cuenta, sustituir los enlaces marcados como próximos por enlaces especiales generados desde Amazon Afiliados. No copiar precios, imágenes ni fichas fuera de las herramientas permitidas por el acuerdo de Amazon.

## Restricción

El proyecto no compra inventario, muestras, dominios, anuncios ni aplicaciones de pago.
